# Customizing the template

Everything company-specific lives in **`src/config/site.ts`**. No component needs to change to re-skin the site for another roofer.

| Section | What it controls |
|---|---|
| `company`, `contact` | Name, tagline, city, license line, phone, email, address, hours |
| `theme` | `accent` and `ink` colors (light mode); dark mode is pitch black by design |
| `photos` | Pexels photo ids (and alt text) for the hero, services, offers, area, reviews and CTA |
| `services` | Marketing copy, process steps and FAQs for `/services` and `/services/<id>` |
| `offers` | Bookable Whop plans: slug, `planId`, title, fallback price, bullets, `kind`, track event |
| `whop` | `accountId` and the product the estimate leads attach to |
| `demoJob` | Label and contract total used by the console's final-balance invoice |
| `serviceAreas`, `financing`, `reviews`, `trust` | The matching page sections |
| `estimateServices` | Options in the estimate form's service dropdown |

## Common changes

**Change a price.** Edit the plan in Whop. The site reads the live price; `priceLabel` is only a fallback.

**Add a bookable offer.** Create the plan in Whop, then add one object to `offers`. The `/checkout/<slug>` route, price display and tracking follow automatically. Use `kind: 'deposit'` for an offer that should save the card on file.

**Add a service page.** Add an entry to `services` with a `photo` key that exists in `photos`.

**Swap photos.** Replace the numeric ids in `photos` with photos from [pexels.com](https://www.pexels.com) (the id is the number in the photo URL). Keep the credit in the footer.

**Change the look.** Colors and type live in the tokens at the top of `src/styles.css`.

## Do not edit

`src/routeTree.gen.ts` is generated by the router on build.
